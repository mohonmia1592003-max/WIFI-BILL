ব্যবহার:
1. index.html = Customer page
2. admin.html = আপনার Admin Panel
3. admin.html খুলে bKash নম্বর সেট করুন।
4. Customer যোগ করুন।
5. Customer index.html-এ ID দিয়ে বিল দেখবে।
6. Customer bKash নম্বর দেখে টাকা পাঠিয়ে Transaction ID জমা করবে।
7. Admin Pending পেমেন্ট দেখে Paid/Reject করবে।

এটি সম্পূর্ণ ফ্রি LOCAL DEMO। ডাটা browser-এর localStorage-এ থাকে, তাই এটি production/shared server নয়।
আসল bKash automatic payment-এর জন্য bKash-এর অনুমোদিত Online Business/Payment Gateway এবং server-side credentials প্রয়োজন। bKash নিজেই online business-এর জন্য payment gateway/API দেয়।
